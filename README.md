A public collection of selected work demonstrating my experience building digital products across mobile and web.

This repository contains the source code and supporting assets for my developer portfolio, including a Flutter application and web implementation. It reflects an earlier stage of my work as I developed my skills across product design, software engineering, and implementation.

## 📱 Flutter Application

`Flutter/jnrapp` is a mobile-oriented Flutter application created to present my professional profile, selected projects, experience, and contact information.

The project uses a structured Flutter codebase with separate screens, models, theming, assets, and Firebase integration.

## 🌐 Web Portfolio

`Web` contains the source for my web-based developer portfolio, implemented without a website builder using HTML, Tailwind CSS, and JavaScript.

The web and Flutter versions were created to explore the same professional identity across different platforms.

## 🎯 Why This Repository Exists

This repository is primarily a record of practical work and experimentation across mobile and web development.

My work has since expanded beyond simply building interfaces. I am particularly interested in product engineering: understanding the problem, designing the underlying system, and making the different parts of a product work together.

My current flagship product is **Fundsverse**, a personal finance platform built with Flutter, Firebase, and a Node.js/TypeScript API. Its main repositories are private and are not included in this public portfolio repository.
